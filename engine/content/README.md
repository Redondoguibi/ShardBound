# Conteúdo do ShardBound

A instalação começa com zero mods. Coloque cada mod em uma subpasta desta pasta, com o seu `mod.json`, ou indique outra pasta com `--mods`.

Para jogar, o conjunto carregado precisa fornecer um mapa ou gerador e um mod de gameplay que crie o jogador. Abra `shardbound_editor.exe` para começar um mapa vazio e criar conteúdo pelo editor ou pelo Assistente IA.
