# Áudio do núcleo

`swing.wav`, `waystone.wav` e `pickup.wav` são sínteses originais, mono PCM16
48 kHz, reproduzíveis com `python tools/create-feedback-audio.py`.
Não usam gravações nem música de outros jogos. São feedbacks curtos; não
substituem a futura direção de áudio, ambientação e trilha do jogo.

`hit.wav` é o efeito provisório preexistente de impacto.
